# Complete Agentic AI Course

This repository is a hands-on collection of projects, notes, and experiments focused on Agentic AI, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), LangChain, LangGraph, and modern AI workflows.

It brings together multiple learning modules and practical code samples designed to help you build, understand, and evaluate agent-based AI systems.

## Repository Overview

The course includes:

- LangChain-Multi-Agent-Research-System — a multi-agent research assistant that searches the web, extracts sources, and writes a final report
- LangGraph-Code — LangGraph workflow and orchestration examples
- Langchain-Single-Agent — single-agent LLM application patterns
- Advanced-RAG — retrieval-augmented generation experiments and advanced patterns
- Corrective-Rag-CRAG — self-correcting RAG workflows
- Self-Rag-Code — self-reflective retrieval pipelines
- Pydantic-Validation — validation and schema enforcement with Pydantic
- Asynchronous Programming — async patterns for AI workloads and APIs
- Agentic AI Interview Preparation — interview prep resources and question sets
- LangChain 1.x & LangGraph Beginner-to-Advanced Study Guide.md — learning notes and study material
- Langchain vs LangGraph — comparison notes and conceptual guidance
- Generative_AI_Study_Guide.pdf — study guide
- guardian_angel_system_simple_explanation.md — conceptual explanation of a simple guardian agent-style architecture

## Getting Started

1. Clone the repository.
2. Open the folder that matches your learning goal.
3. Follow the README or setup instructions inside each project.
4. Install dependencies for the specific project you want to run.
